# Wally mascot assets

Drop the Wally mascot art here and the mockups pick it up automatically:

- `wave.png` — friendly waving pose (used on the onboarding/lifestyle intros, hub, header).
- `thumbs-up.png` — thumbs-up pose (used on the assessment "Thank you" summary).

Square, transparent PNG (≈ 256×256 or larger) works best. Until a file exists, the UI
falls back to a lucide **Bot** icon in a soft accent circle — nothing breaks.

Referenced by `components/wally/WallyMascot.tsx`.
